# Worked examples (hand-derived)

These are the examples behind experiment E4 and `tests/test_worked_examples.py`. **They were derived by the author of
this repository from the factor values in `factors/`; they are not examples published by a standards body or by
the factor publisher.** Each one shows the factor values used, the arithmetic worked out by hand, and the result
written down before the engine was run. The engine is then compared against that number. This checks the
implementation (units, gas conversion, version pinning, market-based fall-back); it does not validate the factors
or the methodology.

Exact conversion constants used in the hand arithmetic: 1 lb = 0.45359237 kg, 1 therm = 0.1 mmBtu, 1 US gallon =
3.785411784 L, 1 mile = 1.609344 km, 1 short ton = 2000 lb. Global warming potentials (AR5, from the Hub's Table 11):
CH4 = 28, N2O = 265; the synthetic TEST set uses CH4 = 25 and N2O = 300.

This file is generated by `tools/make_worked_examples_doc.py`.


## C01. TEST fuel A, 1000 gallon

- Input: 1000 gallon, activity type `TEST_stationary.fuel_a`, factor sets `test-synthetic-v1`
- Hand arithmetic: CO2 10 kg x 1000 = 10000 kg; CH4 100 g x 1000 = 100000 g = 100 kg, x GWP 25 = 2500; N2O 10 g x 1000 = 10000 g = 10 kg, x GWP 300 = 3000; total 10000 + 2500 + 3000 = 15500 kg CO2e
- Expected: scope1 = 15500 kg CO2e
- Comparison tolerance: relative 1e-09

## C02. TEST fuel A, 3785.411784 litres (= 1000 US gallons)

- Hand arithmetic: 3785.411784 L / 3.785411784 L per gallon = 1000 gallon, then as C01 = 15500 kg CO2e
